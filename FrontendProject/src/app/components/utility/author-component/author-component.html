Autor projekta

Staša Trajković

Projekat je realizovan u okviru predmeta Razvoj višeslojnih aplikacija (RVA). Aplikacija predstavlja informacioni sistem za vođenje evidencije o turistickim agencijama.

Frontend tehnologije

  • Angular
  • Angular Material
  • TypeScript

Backend tehnologije

  • Spring Boot
  • Spring Data JPA
  • Hibernate
  • PostgreSQL

Komunikacija između frontend i backend dela sistema ostvarena je korišćenjem REST servisa.
