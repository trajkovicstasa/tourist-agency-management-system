Autor projekta

Ime: Stasa Trajkovic

Projekat je rađen kao vežba za predmet Razvoj višeslojnih aplikacija(RVA).

Tehnologije korišćene u frontend delu:

  • Angular
  • Angular Material
  • TypeScript

U backend delu koristi se:

  • Spring Boot
  • Spring Data JPA
  • Hibernate
  • PostgreSQL

Komunikacija između frontend i backend dela sistema ostvarena je korišćenjem REST servisa.
